# Refinement log

Observations about how this skill performs in real use are recorded in the project's
`docs/SKILL-REFINEMENTS.md` (in the repo where the skill is applied). When you notice a
trigger miss, over-trigger, missed reference, bad advice, or missing guidance while using
this skill, append an entry there using the template at the top of that file. Refinements
to this skill should be driven by those logged observations, not guesses.
